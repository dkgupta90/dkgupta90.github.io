# dkgupta90.github.io

Personal website of Dr. Deepak K. Gupta.

Live at <https://dkgupta90.github.io/>.

## Develop

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Deploy

Pushing to `master` triggers the **Deploy to GitHub Pages** workflow, which
builds a static export and publishes it. Pages must be configured with
**Settings → Pages → Source: GitHub Actions**.

## Structure

- `app/page.tsx` — page content
- `app/globals.css` — styling
- `app/layout.tsx` — page metadata
- `public/` — portrait, CV, favicon
